# Portfólio Pessoal

Este projeto é um portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro. A página reúne informações profissionais, formação, atividades extracurriculares e projetos carregados dinamicamente pela API REST do GitHub.

## Tecnologias utilizadas

- **HTML5**: estruturação semântica das seções do portfólio.
- **CSS3**: estilização, responsividade e organização visual da interface.
- **JavaScript**: controle das abas, busca de projetos e integração com a API do GitHub.
- **GitHub REST API**: carregamento dinâmico dos repositórios e topics dos projetos.

## Finalidade do projeto

Centralizar conteúdos e expor minhas habilidades de forma prática, apresentando experiências, formação, atividades extracurriculares e projetos em uma interface simples, objetiva e acessível.
